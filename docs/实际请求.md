模型1-文生视频
1. 文档地址https://www.volcengine.com/docs/82379/1520757?lang=zh
2. 模拟请求 
""
curl -X POST https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ARK_API_KEY" \
  -d '{
    "model": "doubao-seedance-1-0-pro-250528",
    "content": [
        {
            "type": "text",
            "text": "多个镜头。一名侦探进入一间光线昏暗的房间。他检查桌上的线索，手里拿起桌上的某个物品。镜头转向他正在思索。 --ratio 16:9"
        }
    ]
}'
""
3. 拓展参数
{
    "text":"小猫后空翻 --resolution xxx --ratio  --duration xxx --frames xxx --framespersecond  xxx --seed xxx --camerafixed xxx --watermark xxx"
}

## 统一字段映射（便于前端/模板共用）
| 统一含义 | 统一字段 Key（英文，可多级点号） | 类型/约束 | 默认值 | 模型1-文生视频字段 | 模型2-文生视频字段 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 提示词 | `prompt` | string | 必填 | `content[0].text` (`text`) | `prompt` | 模型1把 ratio/duration 等附加在文本里，需要前置拼接 |
| 反向提示词 | `negative_prompt` | string | 可选 | （无） | `negative_prompt` | 模型1暂无 |
| 模型名 | `model_name` | string | 可选 | `model` | `model_name` |  |
| 画幅/比例 | `aspect_ratio` | string，示例 `16:9` | 可选 | 内嵌在 `text` 中的 `--ratio` | `aspect_ratio` |  |
| 时长 | `duration` | number，秒 | 可选 | 内嵌在 `text` 中的 `--duration` | `duration` |  |
| 分辨率 | `resolution` | string，示例 `1280x720` | 可选 | 内嵌在 `text` 中的 `--resolution` | （无明确字段） | 模型2只用 `aspect_ratio` |
| 帧数 | `frames` | number | 可选 | 内嵌在 `text` 中的 `--frames` | （无） |  |

| 种子 | `seed` | number | 可选 | 内嵌在 `text` 中的 `--seed` | （无） |  |

## 前端筛选/入参配置示例（含 modelFieldMap）
